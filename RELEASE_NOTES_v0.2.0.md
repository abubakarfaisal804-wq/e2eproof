# E2EProof v0.2.0 — public alpha

E2EProof verifies claimed application outcomes with deterministic browser, network, and independent backend checks, then produces a tamper-evident evidence bundle.

## Highlights

- `e2eproof quickstart` runs a real browser-to-backend proof with minimal setup.
- Chromium, Firefox, and WebKit browser selection.
- `e2eproof install-browser` and browser-aware `doctor` checks.
- GitHub composite Action with evidence upload.
- CI definitions for Python 3.11–3.13 on Ubuntu, Windows, and macOS.
- Real 3×3 operating-system/browser proof matrix.
- PyPI Trusted Publishing and GitHub release attestation workflows.
- Stronger public contribution, security, and support metadata.

## Alpha limitations

This release requires explicit contracts and is not a hosted service. It does not replace a security audit, complete accessibility audit, or human review. Public CI results must be checked before relying on any platform-support claim.
