# First-five alpha recruitment

## Public post

I am looking for five developers with a local or staging web app to test
E2EProof, an open-source tool that verifies whether a successful UI action
caused the promised backend result.

Examples:

- a form shows success and exactly one record exists;
- a test payment succeeds and exactly one transaction exists;
- a webhook was received;
- an AI provider really responded instead of a mock or fallback.

The test is asynchronous and should take about 15 minutes. No meeting and no
payment are required. Honest failures are more useful than compliments.

https://github.com/abubakarfaisal804-wq/e2eproof

Guide:
